# Fabrica de Projetos ágeis II IA Turma A Grupo 5



Desenvolver o AvivaLead AI, um sistema que utiliza Inteligência Artificial para analisar empresas cadastradas em um banco de dados e identificar possíveis oportunidades comerciais para a Avivatec.
O sistema irá analisar informações como setor, porte e situação da empresa, recomendar o serviço mais adequado, gerar um score de oportunidade e indicar a prioridade comercial.
